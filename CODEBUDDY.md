# Usora for CodeBuddy

Use the Usora MCP tools and bundled Skill instructions to operate the local Skill Hub.

Natural entry points:

- Initialize my Usora Skill Hub
- Capture this session into Usora
- Show Usora status
- Create a Candidate
- Create a Skill draft
- Clean old Usora plugin cache

Keep Usora local-first and host-neutral. Do not turn Usora into another AI agent, cloud service, dashboard, marketplace, team system, or payment product.
